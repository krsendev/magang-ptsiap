# Repostiory Portfolio Minggu 1-2
Repository ini dibuat sebagai wadah yang menampung hal-hal yang telah dikerjakan pada minggu ke-1 hingga minggu ke-2.
Di dalam repository ini memuat 3 hal, yaitu:
* Koleksi Postman
* Skrip bash
* Panduan SSH

## Koleksi Postman
Di dalam folder 'http' terdapat 3 koleksi Postman, diantaranya:
1. Latihan HTTP, berisi semua request Postman hasil latihan mandiri dengan menggunakan 7 HTTP method
2. Boss Battle, berisi jawaban dari setiap tantangan Boss Battle pada tanggal 7 Agustus 2026
3. Ronde Sabotase, berisi request Postman yang telah disabotase dan berhasil terselesaikan

## Skrip bash
Di dalam folder 'skrip' terdapat 5 skrip bash yang merupakan hasil dari latihan mandiri, yaitu:
1. backup.sh, merupakan skrip untuk backup data yang disertai waktu realtime kapan backup tersebut dibuat
2. cek.sh, merupakan skrip untuk menentukan sebuah bilangan itu ganjil atau genap
3. halo.sh, merupakan skrip sederhana untuk menampilkan nama yang ditulis di dalamnya
4. info.sh, merupakan skrip yang memiliki banyak fungsi seperti menampilkan nama user yang sedang aktif, menampilkan list group dari user, menampilkan lokasi direktori yang sedang diakses user, dan menampilkan tanggal saat ini. Selain itu juga terdapat uji coba parameter dan argumen pada skrip bash
5. loop.sh, merupakan skrip yang berfungsi melakukan perulangan angka 1-10 dan menampilkan 5 produk kerupuk dari sebuah array

## Panduan SSH
Di dalam folder 'docs' terdapat sebuah file markdown yang berisi panduan untuk mengakses VM/VPS Sandbox menggunakan SSH.
