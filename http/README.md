# Collection Postman

## Latihan HTTP - Krisna
Merupakan collection Postman yang berisi semua request hasil latihan mandiri dengan menggunakan ketujuh HTTP method.

## Boss Battle
Merupakan collection Postman yang berisi jawaban setiap tantangan Boss Battle di tanggal 7 Agustus 2026.

## Ronde Sabotase
Merupakan collection Postman yang berisi request yang telah disabotase dan telah diselesaikan.
