# Fungsi Setiap Skrip

## backup.sh
Script ini berfungsi untuk melakukan backup data disertai dengan waktu realtime backup tersebut dibuat.

## cek.sh
Script ini berfungsi untuk menentukan sebuah bilangan itu ganjil atau genap.

## halo.sh
Script ini menampilkan nama yang ditulis didalamnya.

## info.sh
Script ini berfungsi untuk:
* Menampilkan user yang sedang aktif/digunakan saat ini
* Menampilkan list group dari user saat ini
* Menampilkan lokasi direktori yang sedang diakses user saat ini
* Menampilkan tanggal saat ini, dan
* Uji coba parameter dan argumen pada script bash

## loop.sh
Script ini melakukan perulangan angka 1-10 dan menampilkan 5 produk krupuk dari array
